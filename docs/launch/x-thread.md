## 6 / the packages

```
five MIT npm packages:

@vibeclubs/vibe-mix         — three-layer web audio mixer
```

## 7 / the vetoes

```
what we deliberately don't ship:

- breakout rooms
- host controls
- recording-by-default
- calendar features
- in-app payments on the OSS core

zoom exists. google calendar exists. those aren't problems vibeclubs is solving.
```
