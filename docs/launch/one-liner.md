## 3 · One-paragraph (≤ 120 words)

> Vibeclubs is the format for builders who want to ship alongside other builders. The directory at vibeclubs.ai lists public vibeclubs — pick one, hit the join link, lock in for 90 minutes on whatever platform the host already uses. The Chrome extension overlays a synced pomodoro and a three-fader audio mixer (ambient + Suno music + page audio) onto any tab. When the timer stops, Claude writes a one-line recap. The session card lands on your profile. Five MIT npm packages let you fork the mixer, the sync, the recap prompt, the card renderer, and the music bridge into anything. Free forever to host. Pro ships in Sprint 2.

Use for: README hero paragraph, HN comment, podcast intro, email signature.

## 4 · Long-form (≤ 350 words)

> Vibeclubs started as a question: why do solo builders feel more productive on a Discord co-working channel than alone in a quiet room? The answer wasn't social pressure — it was a ritual. Three tools, every time: ambient music, a pomodoro timer, and a call. Builders duct-tape them together because none of the calendar apps or video platforms get the texture right.
>
> So we formalized the ritual.
>
> A vibeclub is a format. Like "hackathon" or "book club." You can run one on Meet, on Discord, on Zoom, in a coffee shop with everyone on Wi-Fi. The format doesn't care. What we built is the connective tissue: a directory at vibeclubs.ai where any host can list a public club, a Chrome extension that overlays a synced timer and an audio mixer on whatever tab you're already on, and five MIT npm packages so anyone can fork the pieces into Electron apps, Raycast extensions, or tools nobody's built yet.
>
> The directory has two paths. The OSS path: drop a markdown file in /content/clubs/ via PR. Zero backend. Your club lands on /explore after merge. The hosted path: /start with a magic link, get a private listing or real-time presence. They both render the same way.
>
> The recap is intentionally small. Claude watches the focus blocks. Never interrupts, never coaches. When the timer stops, it writes a one-line acknowledgement that lands on your profile card. You screenshot the card. You post the card. That's how the format spreads.
>
> Hosting is free forever. The extension is free. The packages are MIT. Pro ($12/mo, ships Sprint 2) wires Suno music gen into the music fader and runs full Claude recaps for hosts who want the long version. The OSS core never goes behind a paywall — that's a load-bearing constraint, not a marketing claim.
>
> Vibeclubs.ai. Lock in.

Use for: about page, "what we're building" essay, investor cold-email if Frank ever raises, README full description.
