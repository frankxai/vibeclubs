# Vibeclubs v0.2.0 release candidate

This candidate captures the first complete repository history through production
commit `417dc5185e7175e365323483808bf38032f2abaa` (2026-07-24). It is a draft:
no `v0.2.0` tag, GitHub release, or npm package publication exists yet.

## What changed

- Made the five-state ritual tangible: host, join, focus, ship, recap.
- Added the local proof flow, directory content, playbook, extension foundations,
  shared packages, and the Vibeclubs design system.
- Added explicit privacy boundaries: local-first proof, per-person AI recap opt-in,
  and no page-content reading by the extension.
- Aligned the production host, canonical metadata, robots, sitemap, and Vercel
  deployment with `vibeclubs.ai`.
- Added CI, voice and club audits, built-truth checks, and operational handovers.
