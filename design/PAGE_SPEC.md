# Homepage Page Spec

## Job

Move a skeptical builder from “What is this?” to a completed host → join → focus → ship → recap proof without sign-in.

## Sequence

1. First viewport: open-format position, direct promise, proof CTA, GitHub trust route.
2. Product truth panel: five explicit states, labeled local.
3. Working proof: real six-second timer plus deterministic recap and downloadable SVG.
4. Business model: open core plus hosted team continuity, with unshipped capabilities described conditionally.
5. Final choice: repeat proof or enter configured hosted flow.

## Responsive contract

Mobile stays single-column. The primary sentence and proof CTA precede the instrument panel. The five-state rail stacks and the proof controls remain keyboard reachable. No essential state relies on hover.

## Measurement

Track proof start, timer completion, recap creation, card download, and hosted-start intent only after a privacy-reviewed analytics implementation exists. Do not simulate counters.
