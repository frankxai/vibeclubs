# Vibeclubs Site Operator

Use this repo skill for homepage, activation, trust, and hosted-flow work.

## Required sequence

1. Read `VISION.md`, `AGENTS.md`, `DESIGN.md`, `TASTE.md`, and `SYSTEM.md`.
2. State the exact capability being made visible and locate its source package or API route.
3. Update `design/PAGE_SPEC.md` and `design/SCENE_BRIEF.md` before visual implementation.
4. Keep the local proof browser-only and deterministic.
5. Keep optional AI observation off by default and disclose its structured data boundary.
6. Use the canonical voice: vibeclub / host / crew / lock in / ship.
7. Run frozen install, voice audit, lint, typecheck, tests, production build, and one visual capture attempt.
8. Keep releases draft until visual QA and live preview inspection pass.

## Never claim

- A hosted capability works without configuration evidence.
- The AI sees audio, screen, page, or chat content.
- A sample attendee, timer, recap, or card is live activity.
- A paid tier is available merely because a pricing component exists.
